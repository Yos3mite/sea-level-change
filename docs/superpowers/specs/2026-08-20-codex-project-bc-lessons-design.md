## 目标 B 新增内容

目标 B 的新增段落包含以下约束：

1. 每个 Level-3 变量都要登记观测对象、符号、单位、参考面和正方向。
2. GIA、当代弹性负荷响应和 OBD 分开处理；产品已去除 GIA 时禁止再次校正。
3. OBD 采用有符号向上为正的定义，进入 `mass + steric + OBD` 预算侧，不加到已经观测到的卫星测高 SSH/GMSL 上。
4. 自制质量场与 OBD 尽量使用同一套 Level-2 系数、低阶项、GIA、滤波和掩膜，避免处理链不一致。
5. 原始月份、观测月份、补齐月份和最终月轴分别保留；缺测不得静默填零。
6. 多中心参考产品先分别完成缺测处理，再求平均；中心平均和产品间离散度同时输出。
7. 主结果与海岸缓冲、滤波、GIA、低阶项等敏感性试验分开命名，不把敏感性结果当成默认结果。
8. 论文参考趋势、配置采用值和实际曲线拟合值分别保存，算法不得反向调节曲线以命中论文数值。
9. 每次运行保存配置、输入/辅助文件/处理代码哈希、实际参数、警告和不可变输出目录。

## 目标 C 新增内容

目标 C 的新增段落包含以下经验：

1. 每条图线先定义科学含义和点对点公式，再编写绘图代码。
2. 测高 GMSL、质量海平面、比容海平面和 OBD 预算闭合诊断分别保存；Figure 1 的质量加比容曲线不包含 OBD。
3. 去季节、去趋势、中心滑动平均和显示平移分层处理；显示平移不得写回科学序列或参与统计。
4. 月轴固定时，同时报告科学序列月数和中心滑动平均后的有效月数。
5. 指标表同时保存参考/采用趋势和实际曲线重拟合趋势，并标明 OLS 或 HAC 不确定度口径。
6. 每幅图同时输出 PNG、PDF、绘图数据 CSV、指标表、配置快照、方法报告和运行清单。
7. 自动检查点对点恒等式、趋势容差、有效月数、输入输出哈希和重复运行一致性；PNG 与 PDF 渲染结果都要人工检查。
8. 新处理方案生成独立版本，保留旧版，禁止覆盖后再用同一文件名解释不同科学口径。
